1""" 

2Beta from Phase 

3-------------------- 

4 

5 Implements beta and alpha function calculation from phase advance measurements 

6 

7 Two implementations are provided: 

8 

9 - The **Analytical N-BPM method**, described in: 

10 

11 Langner, A. et al., "Analytical N beam position monitor method", 

12 Phys. Rev. Accel. Beams 20, 111002 (2017). 

13 https://cds.cern.ch/record/2307554 

14 

15 It uses all valid BPM triplet combinations within a configurable range, propagates both phase measurement uncertainties 

16 and systematic lattice errors (quadrupole field gradient errors, quadrupole longitudinal misalignments, BPM longitudinal 

17 misalignments and sextupole horizontal misalignments) through an analytical covariance matrix. 

18 

19- The **3-BPM method**, originally from: 

20 

21 Castro, P. "Luminosity and beta-function measurements at the electron-positron collider ring LEP" 

22 Ph.D Thesis, University of Valencia, 1996. 

23 https://repository.cern/records/eny2v-4y338 

24 

25 The initial, simple version using only adjacent BPM triplets, with phase measurement uncertainties only. 

26"""

83def calculate( 

84 meas_input: DotDict, 

85 tunes: TuneDict, 

86 phase_dict: PhaseDict, 

87 header_dict: dict[str, Any], 

88 plane: str, 

89) -> tuple[tfs.TfsDataFrame, dict[str, Any]]: 

90 """ 

91 Calculates betas and alphas from phase advances. This will dispatch to 

92 use either the ``n_bpm_method`` or ``three_bpm_method``, based on the 

93 passed option. 

94 

95 The measured and model tunes passed downstream are selected based on the 

96 compensation model: free (natural) tunes Q/QM are used when no compensation 

97 was applied, while driven tunes QF/QFM are used otherwise. 

98 

99 Args: 

100 meas_input: `OpticsInput` object with optics CLI options. 

101 tunes: `TuneDict` contains model and measured tunes (incl. free motion). 

102 phase_dict: `PhaseDict` containing phase advances between BPMs from model, 

103 measurements (incl. errors). 

104 header_dict: dictionary of header items common for all output files. 

105 plane: marking the horizontal or vertical plane, **X** or **Y**. 

106 

107 Returns: 

108 Tuple of the results `TfsDataFrame` (betas, alphas, errors, delta columns) 

109 and the output file header dictionary. 

110 """ 

111 # Figure out which tunes to use and pass down 

112 meas_and_model_tunes = ( 

113 (tunes[plane]["Q"], tunes[plane]["QM"] % 1) 

114 if meas_input.compensation == CompensationMode.NONE 

115 else (tunes[plane]["QF"], tunes[plane]["QFM"] % 1) 

116 ) 

117 

118 # Dispatch to the required reconstruction method 

119 if meas_input.three_bpm_method: 

120 beta_df = three_bpm_method(meas_input, phase_dict, plane, meas_and_model_tunes) 

121 error_method = Methods.THREE_BPM 

122 else: 

123 # Here error_method lets us know if we have applied systematic uncertainties 

124 beta_df, error_method = n_bpm_method(meas_input, phase_dict, plane, meas_and_model_tunes) 

125 

126 # We provide information on the rms beta-beating 

127 LOGGER.info(f"Errors from {error_method}") 

128 rmsbb = 100 * ( 

129 stats.weighted_rms( 

130 beta_df.loc[:, f"{DELTA}{BETA}{plane}"].to_numpy(), 

131 errors=beta_df.loc[:, f"{ERR}{DELTA}{BETA}{plane}"].to_numpy(), 

132 ) 

133 ) 

134 LOGGER.info(f" - RMS beta beat: {rmsbb:.3f}%") 

135 header = _get_header(header_dict, error_method, meas_input.range_of_bpms, rmsbb) 

136 return beta_df, header

144def n_bpm_method( 

145 meas_input: DotDict, 

146 phase: PhaseDict, 

147 plane: str, 

148 meas_and_mdl_tunes: tuple[float, float] 

149) -> tuple[tfs.TfsDataFrame, str]: 

150 """ 

151 Calculates betas and alphas using all BPM triplet combinations within a sliding window 

152 of `range_of_bpms` BPMs centred on each probed BPM. Please refer to theory at 

153 https://cds.cern.ch/record/2307554. 

154 

155 For each probed BPM i, a total of m = range_of_bpms // 2 neighbors are selected on 

156 each side. Every valid pair (j, k) within those neighbors contributes to form a BPM 

157 triplet (i, j, k) from which βi and ⍺i are estimated individually via the function 

158 ``calculate_beta_alpha_from_single_combination``. The estimates of all combinations 

159 are combined with covariant weighting using the analytical covariance matrix: 

160 

161 V_β = T · Σ · Tᵀ 

162 

163 where T is the Jacobian of (βi, ⍺i) with respect to all error sources, and Σ is the 

164 diagonal matrix of errors sources variances (phase noise + systematic lattice errors). 

165 See ``_covariant_weighting`` for the combination step. 

166 

167 The best-knowledge model is used for the beta/alpha/phase-advance values fed into 

168 the error propagation (Jacobian), while the normal model provides the output reference 

169 columns ("MDL" suffix). If no best-knowledge model is available, both fall back to the 

170 same model. 

171 

172 Args: 

173 meas_input: `OpticsInput` object with optics CLI options. 

174 phase: `PhaseDict` of phase matrices of measurement with errors and model tfs (bpm x bpm). 

175 plane: marking the horizontal or vertical plane, **X** or **Y**. 

176 meas_and_mdl_tunes: measured and model tunes. 

177 

178 Returns: 

179 `TfsDataFrame` containing betas and alfas from phase, as well as their errors. 

180 """ 

181 # Determine the range of BPMs to draw combinations from (BPM triplets) 

182 n_bpms: int = meas_input.range_of_bpms 

183 n_bpms_phases: int = len(phase[MEASUREMENT].index) 

184 if n_bpms_phases < n_bpms: 

185 LOGGER.warning( 

186 f"Found {n_bpms_phases} BPMs, but {n_bpms} " 

187 "were requested in N-BPM method. Using all available BPMs instead," 

188 "the results will still be correct." 

189 ) 

190 n_bpms = n_bpms_phases 

191 

192 # Ensure at least 3 since we need BPM triplets 

193 if n_bpms < 3: 

194 raise ValueError( 

195 "At least 3 BPMs are required for N-BPM method!" 

196 f"Instead a range of {n_bpms} was requested." 

197 ) 

198 

199 # Get the accelerator elements including systematic errors, then 

200 # (best knowledge) model values and tunes 

201 elements, error_method = get_elements_with_errors(meas_input, plane) 

202 beta_df = _get_filtered_model_df(meas_input, phase, plane) 

203 bk_model = _get_filtered_model_df(meas_input, phase, plane, best=True) 

204 tune, mdltune = meas_and_mdl_tunes 

205 

206 nbpms: int = len(bk_model.index) 

207 n_comb: np.ndarray = np.zeros(nbpms, dtype=int) 

208 

209 # Prepare array for results - this one will contain the 

210 # [beta, betaerr, alfa, alfaerr] for each probed BPM 

211 betas_alfas = np.zeros((len(phase[MEASUREMENT].index), 4)) 

212 

213 m = int(n_bpms / 2) # half window: probed BPM has m neighbors on each side 

214 loc_range = np.arange(-m, m + 1) # relative indices [-m, ..., 0, ..., m] 0 is the probed BPM 

215 

216 # Phase advances are stored in units of 2π, convert to radians for cotangent calculations 

217 phases_meas = phase[MEASUREMENT] * PI2 

218 phases_err = phase[f"{ERR}{MEASUREMENT}"] * PI2 

219 phases_err.where(phases_err.notnull(), 1, inplace=True) # replace NaN errors with 1 

220 

221 # We go find combinations within the given range for all BPMs in the model 

222 for indx, probed_bpm_name in enumerate(bk_model.index): 

223 # Find the first and last BPMs in the range 

224 indx_el_first: int = elements.index.get_loc(bk_model.index[(indx - m) % nbpms]) 

225 indx_el_last: int = elements.index.get_loc(bk_model.index[(indx + m) % nbpms]) 

226 mu_column: str = f"{PHASE_ADV}{plane}" 

227 

228 # We build a sliding window of (2m+1) BPMs centered on the probed one. 

229 # For BPMs near the start/end of the ring the window wraps around. The 

230 # tune shift (Q·2π) is subtracted / added to keep phases monotonically 

231 # increasing across the wrap boundary 

232 # fmt: off 

233 if indx < m: 

234 outer_meas_phase_adv = pd.concat((phases_meas.iloc[indx, nbpms + indx - m :] - tune * PI2, phases_meas.iloc[indx, : indx + m + 1])) 

235 outer_meas_err = pd.concat((phases_err.iloc[indx, nbpms + indx - m :], phases_err.iloc[indx, : indx + m + 1])) 

236 outer_mdl_ph = np.concatenate((bk_model.iloc[nbpms + indx - m :][mu_column] - mdltune, bk_model.iloc[: indx + m + 1][mu_column])) * PI2 

237 outer_elmts = pd.concat((elements.iloc[indx_el_first:], elements.iloc[: indx_el_last + 1])) 

238 outer_elmts_ph = np.concatenate((elements.iloc[indx_el_first:][mu_column] - mdltune, elements.iloc[: indx_el_last + 1][mu_column])) * PI2 

239 elif indx + m >= nbpms: 

240 outer_meas_phase_adv = pd.concat((phases_meas.iloc[indx, indx - m :], phases_meas.iloc[indx, : indx + m + 1 - nbpms] + tune * PI2)) 

241 outer_meas_err = pd.concat((phases_err.iloc[indx, indx - m :], phases_err.iloc[indx, : indx + m + 1 - nbpms])) 

242 outer_mdl_ph = np.concatenate((bk_model.iloc[indx - m :][mu_column], bk_model.iloc[: indx + m + 1 - nbpms][mu_column] + mdltune)) * PI2 

243 outer_elmts = pd.concat((elements.iloc[indx_el_first:], elements.iloc[: indx_el_last + 1])) 

244 outer_elmts_ph = np.concatenate((elements.iloc[indx_el_first:][mu_column], elements.iloc[: indx_el_last + 1][mu_column] + mdltune)) * PI2 

245 else: 

246 outer_meas_phase_adv = phases_meas.iloc[indx, indx + loc_range] 

247 outer_meas_err = phases_err.iloc[indx, indx + loc_range] 

248 outer_mdl_ph = bk_model.iloc[indx + loc_range][mu_column].to_numpy() * PI2 

249 outer_elmts = elements.iloc[indx_el_first : indx_el_last + 1] 

250 outer_elmts_ph = elements.iloc[indx_el_first : indx_el_last + 1][mu_column].to_numpy() * PI2 

251 # fmt: on 

252 

253 # sin²(φ_l - φ_mdl_j): (n_elements × n_bpms_window) matrix of squared sines of the 

254 # model phase advance from every element l to every window BPM j. 

255 sin_squared_elements = np.square( 

256 np.sin(outer_elmts_ph[:, np.newaxis] - outer_mdl_ph[np.newaxis, :]) 

257 ) 

258 

259 with np.errstate(divide="ignore"): 

260 # cot(φ₁ⱼ): measured cotangents for each window BPM j, phase from probed BPM 

261 cot_meas = 1.0 / np.tan(outer_meas_phase_adv.to_numpy()) 

262 # cot(φ_mdl_1j): model cotangents relative to the probed BPM's model phase (index m) 

263 cot_model = 1.0 / np.tan(outer_mdl_ph - outer_mdl_ph[m]) 

264 

265 # Numerical stability filter: discard BPMs whose phase advance is too close to 

266 # a multiple of π (|cot| > COT_THRESHOLD ≈ π/ZERO_THRESHOLD), where the cotangent 

267 # diverges and derivatives become unreliable (paper Sec. III, stability criterion) 

268 patter = (np.abs(cot_meas) <= COT_THRESHOLD) & (np.abs(cot_model) <= COT_THRESHOLD) 

269 

270 # Diagonal of the covariance matrix Σ for all error sources. Note systematic errors 

271 # have been loaded as squares from error_deffs.txt and quadrupole dK1 was multiplied 

272 # by length in order to obtain the value for the field gradients (lng = length(outer_elmts)) 

273 # [0 : n_bpms] → σ²_φⱼ (phase measurement variance for each window BPM j) 

274 # [off1 : off1 + lng] → σ²_ΔK1L = (dK1 · K1L)² variance (quad gradient field errors) 

275 # [off2 : off2 + lng] → σ²_ΔX = dX² (sextupole transverse misalignment) 

276 # [off3 : off3 + lng] → σ²_KdS = (dS · K1L)² (quad longitudinal misalignment) 

277 # [off4 : off4 + lng] → σ²_mKdS (upstream drift of misaligned quad, thin-lens) 

278 diag = np.concatenate( 

279 ( 

280 np.square(outer_meas_err.to_numpy()), 

281 outer_elmts.loc[:]["dK1"], 

282 outer_elmts.loc[:]["dX"], 

283 outer_elmts.loc[:]["KdS"], 

284 outer_elmts.loc[:]["mKdS"], 

285 ) 

286 ) 

287 

288 outer_elmts = outer_elmts.rename(columns={f"{BETA}{plane}": "BETA"}) 

289 

290 # Gather all valid BPM pairs (x, y) forming a triplet with the probed BPM (x < y enforces no duplicates) 

291 # In the conditions from this comprehension, a pair is rejected if: 

292 # - either BPM failed the cotangent stability filter above, 

293 # - |cot_mdl_x - cot_mdl_y| ≤ ZERO_THRESHOLD (near-degenerate model denominator), or 

294 # - cot_mdl and cot_meas differences have opposite signs (unphysical: would invert β sign) 

295 index_tuples = [ 

296 (x, y) 

297 for x in loc_range[patter] + m 

298 for y in loc_range[patter] + m 

299 if (x < y) 

300 and (abs(cot_model[x] - cot_model[y]) > ZERO_THRESHOLD) 

301 and (np.sign(cot_model[x] - cot_model[y]) * np.sign(cot_meas[x] - cot_meas[y]) > 0) 

302 ] 

303 

304 # We allocate arrays for the covariance matrices & results for beta and alpha. 

305 # As per docstring these are V_β = T_β · Σ · T_βᵀ and V_α = T_α · Σ · T_αᵀ 

306 # Each row of is the gradient ∇β (or ∇α) for one triplet combination 

307 # V_β[i,j] = covariance between the β estimates from triplets i and j 

308 mat_t_beta = np.zeros((len(index_tuples), len(diag))) 

309 mat_t_alpha = np.zeros((len(index_tuples), len(diag))) 

310 betas = np.empty(len(index_tuples)) 

311 alphas = np.empty(len(index_tuples)) 

312 

313 # For each given combination we apply the calculations to determine 

314 # beta, alpha and the covariance matrices terms. See that function. 

315 for i, c in enumerate(index_tuples): 

316 betas[i], alphas[i], mat_t_beta[i], mat_t_alpha[i] = ( 

317 calculate_beta_alpha_from_single_combination( 

318 c, 

319 sin_squared_elements, 

320 outer_elmts, 

321 cot_model, 

322 cot_meas, 

323 outer_meas_phase_adv, 

324 probed_bpm_name, 

325 bk_model.at[probed_bpm_name, f"{BETA}{plane}"], 

326 bk_model.at[probed_bpm_name, f"{ALPHA}{plane}"], 

327 meas_input.range_of_bpms, 

328 ) 

329 ) 

330 

331 # Now we have the values, we move on to the error calculations from the covariance terms 

332 # Zero-variance entries (error sources not defined for this window) are excluded before 

333 # building the covariance matrix to avoid degenerate rows/columns 

334 mask = diag != 0 

335 mat_diag = np.diag(diag[mask]) # make that a diagonal matrix (we only had diagonal terms) 

336 

337 # Below we compute the covariance matrices for β and ⍺ - explained for β below 

338 # V_β = T_β[:,active] · Σ_active · T_β[:,active]ᵀ — covariance matrix of all β estimates 

339 # Off-diagonal entries V_β[i,j] represent correlation between estimates i and j arising 

340 # from shared error sources (e.g. two BPM triplets using the same quadrupole) 

341 mat_v_beta = np.dot(mat_t_beta[:, mask], np.dot(mat_diag, np.transpose(mat_t_beta[:, mask]))) 

342 mat_v_alpha = np.dot(mat_t_alpha[:, mask], np.dot(mat_diag, np.transpose(mat_t_alpha[:, mask]))) 

343 

344 if np.any(mat_v_beta) and np.any(mat_v_alpha): 

345 # Combine all triplet estimates into a single BLUE-weighted β and α with 

346 # propagated error. See _covariant_weighting for the derivation 

347 beti, beterr = _covariant_weighting(mat_v_beta, betas) 

348 alfi, alferr = _covariant_weighting(mat_v_alpha, alphas) 

349 n_comb[indx] = len(betas) # how many combinations get weighted for this BPM's error bar 

350 else: 

351 # All-zero covariance arises when: no valid BPM triplets passed the patter/index_tuples 

352 # filters, or all error sources were zero (no phase noise AND no systematic errors). 

353 # In either case there is no valid estimate for this BPM; skip and leave betas_alfas at 0 

354 LOGGER.debug( 

355 f"ValueError or no combinations left at {probed_bpm_name}.\n" 

356 f"betas:\n{betas}\n" 

357 f"alphas:\n{alphas}" 

358 ) 

359 continue 

360 

361 betas_alfas[indx, :] = np.array([beti, beterr, alfi, alferr]) 

362 

363 # ----- By now we have finished the big loop, got results for all BPMs ----- # 

364 

365 # Unpack the per-BPM results from the loop into the output DataFrame. 

366 # BPMs that hit the 'continue' above remain at zero in betas_alfas (as 

367 # initialised) and are filtered below. 

368 beta_df[f"{BETA}{plane}"] = betas_alfas[:, 0] 

369 beta_df[f"{ERR}{BETA}{plane}"] = betas_alfas[:, 1] 

370 beta_df[f"{ALPHA}{plane}"] = betas_alfas[:, 2] 

371 beta_df[f"{ERR}{ALPHA}{plane}"] = betas_alfas[:, 3] 

372 beta_df["NCOMB"] = n_comb 

373 

374 # Now we do some quality filtering 

375 

376 # Drop BPMs for which the loop produced no valid combinations 

377 invalid_mask = beta_df["NCOMB"] == 0 

378 if np.any(invalid_mask): 

379 LOGGER.debug(f"No valid combinations for BPMs: {list(beta_df.index[invalid_mask])}.") 

380 beta_df = beta_df.loc[beta_df["NCOMB"] > 0] 

381 

382 # Drop BPMs with a non-physical negative beta (occurs with very noisy phase advances) 

383 beta_df = beta_df.loc[beta_df[f"{BETA}{plane}"] > 0] 

384 

385 # Drop BPMs where the estimated error exceeds both the measured and model beta. 

386 # Keeping at least one comparison to β_mdl guards against cases where β_meas 

387 # itself is already severely distorted somehow. 

388 too_high_error_mask = np.logical_or( 

389 beta_df[f"{BETA}{plane}"] > beta_df[f"{ERR}{BETA}{plane}"], 

390 beta_df[f"{BETA}{plane}{MDL}"] > beta_df[f"{ERR}{BETA}{plane}"], 

391 ) 

392 beta_df = beta_df.loc[too_high_error_mask] 

393 

394 # We add the "DELTA{...}" columns as deviations from the model 

395 # values and then we return 

396 beta_df = _calc_and_add_delta_columns(beta_df, plane) 

397 return beta_df, error_method

400def get_elements_with_errors(meas_input: DotDict, plane: str) -> tuple[pd.DataFrame, str]: 

401 """ 

402 Loads the accelerator lattice elements with their systematic error variances, 

403 ready to be windowed per probed BPM in ``n_bpm_method``. 

404 

405 Reads the machine-specific error definition file (``error_defs_file``) and 

406 populates four variance columns on the element table via ``_assign_uncertainties``: 

407 ``dK1``, ``dX``, ``KdS``, ``mKdS``. 

408 

409 Only elements with at least one non-zero error source are retained (see 

410 ``_assign_uncertainties`` for the filtering logic). The returned ``error_method`` 

411 string is used downstream to label the output file header and the RMS beta-beat 

412 log message. 

413 

414 Args: 

415 meas_input: `OpticsInput` object with optics CLI options. Must have 

416 ``accelerator.error_defs_file`` set and ``accelerator.elements`` populated. 

417 plane: marking the horizontal or vertical plane, **X** or **Y**. 

418 

419 Returns: 

420 Tuple of: 

421 - elements DataFrame indexed by element name with columns: 

422 S, K1L, K2L, MU{plane}, BET{plane}, dK1, dX, KdS, mKdS, BPMdS. 

423 - error_method string: ``Methods.A_NBPM`` if at least one systematic error 

424 was assigned, ``Methods.NO_ERR`` otherwise. 

425 

426 Raises: 

427 OSError: if ``error_defs_file`` is None (no error definition file configured). 

428 """ 

429 if meas_input.accelerator.error_defs_file is None: 

430 raise OSError("Error definition file could not be found") 

431 

432 # Extract only the columns needed for the Jacobian in 'calculate_beta_alpha_from_single_combination': 

433 # K1L → scaled into dK1 variance; 

434 # K2L → multiplied into the dX Jacobian entry; 

435 # MU{plane} and BET{plane} → model phase advances and betas used in the sin² / bet_sin terms. 

436 # Then _assign_uncertainties attributes the systematic errors from file 

437 elements = meas_input.accelerator.elements.loc[:, [S, "K1L", "K2L", f"{PHASE_ADV}{plane}", f"{BETA}{plane}"]] 

438 LOGGER.debug("Accelerator Error Definition") 

439 elements = _assign_uncertainties(elements, meas_input.accelerator.error_defs_file) 

440 

441 # Check whether any systematic error was actually assigned to at least one element. 

442 # dK1, dX and KdS are checked but mKdS is derived from KdS so it needs no separate check. 

443 # BPMdS is stored but not currently included in the diag vector so not checked. 

444 errors_assigned = ( 

445 len(elements["dK1"].to_numpy().nonzero()[0]) 

446 + len(elements["dX"].to_numpy().nonzero()[0]) 

447 + len(elements["KdS"].to_numpy().nonzero()[0]) 

448 ) > 0 

449 if not errors_assigned: 

450 LOGGER.warning( 

451 "No systematic errors were given or no element was found for the given " 

452 "error definitions. The systematic lattice errors are not used." 

453 ) 

454 

455 # Assign the error method (remember we're only called for analytical N-BPM): 

456 # A_NBPM = full analytical method with systematic errors 

457 # NO_ERR = only phase measurement uncertainties propagated (reduced accuracy) 

458 error_method = Methods.A_NBPM if errors_assigned else Methods.NO_ERR 

459 return elements, error_method

462def calculate_beta_alpha_from_single_combination( 

463 c: tuple[int, int], 

464 sin_squared_elements: np.ndarray, 

465 outer_elmts: pd.DataFrame, 

466 cot_model: np.ndarray, 

467 cot_meas: np.ndarray, 

468 outer_meas_phase_adv: pd.Series, 

469 probed_bpm_name: str, 

470 betmdl1: float, 

471 alfmdl1: float, 

472 range_of_bpms: int, 

473) -> tuple[float, float, np.ndarray, np.ndarray]: 

474 """ 

475 Computes β₁ and α₁ for one BPM triplet (probed BPM 1, reference BPMs x and y) 

476 and builds the corresponding rows of the Jacobian matrices T_β and T_α used for 

477 covariance propagation in ``n_bpm_method``. 

478 

479 Note about the Jacobian structure (Eq. 22): T = (T^φ T^K T^s) 

480 The full Jacobian is split into three blocks: phase uncertainty T^φ, 

481 quadrupole field errors T^K and BPM longitudinal misalignments T^s. 

482 Sextupole horizontal misalignments enter into T^K via Eq (13-14) as 

483 effective quadrupole errors due to feed-down. Here K2L comes into play. 

484 Longitudinal quadrupole misalignments are decomposed into two thin-lens 

485 elements at the quadrupole edges (section II.B, Fig. 3): forward (KdS) 

486 and backward (mKdS). 

487 

488 The returned `betaline` and `alfaline` are 1D vectors of length (2m+1, 4*n_elements), 

489 each one being a row of T_β / T_α. Their layout matches the `diag` vector in 

490 ``n_bpm_method`` (see below for the blocks). 

491 

492 Args: 

493 c: tuple, pair of relative indices (ix, iy) for the two reference BPMs of this triplet. 

494 Indices run 0 ... 2m with the probed BPM at position m. 

495 sin_squared_elements: (n_elements * n_bpms_window) array of squared sines of the 

496 model phase advance from every element l to every window BPM j. In there, 

497 entry [l, j] = sin²(φ_l - φ_mdl_j). Pre-computed in ``n_bpm_method``. 

498 outer_elmts: DataFrame of lattice elements in the window, which contains the BETA, 

499 K1L, K2L, dK1, dX, KdS and mKdS column (after loading systematic errors). 

500 cot_model: 1-D array of model cotangents cot(φ_mdl_1j - φ_mdl_11), length 2m+1; 

501 where entry m is - by construction (probed BPM to itself). 

502 cot_meas: 1D array of measured cotangents cot(φ_meas_1j), of length 2m+1. 

503 outer_meas_phase_adv: measured phase advances (radians) from the probed BPM 

504 to each BPM in the window (index carries BPM names used for element lookup). 

505 probed_bpm_name: The name of BPM 1 whose β and α are being estimated. 

506 betmdl1 (float): model β at the probed BPM. 

507 alfmdl1 (float): model α at the probed BPM. 

508 range_of_bpms: total window width. 

509 

510 Returns: 

511 A tuple (β₁, α₁, betaline, alfaline) where betaline and alfaline are the 

512 Jacobian rows for this combination, to be stacked into the complete Jacobian 

513 matrices T_β and T_α inside of ``n_bpm_method``. 

514 """ 

515 m = int(range_of_bpms / 2) # half window: probed BPM has m neighbors on each side 

516 ix = c[0] # index of BPM i 

517 iy = c[1] # index of BPM y 

518 dif_cot_model = cot_model[ix] - cot_model[iy] 

519 

520 # Beta estimate at probed BPM for this triplet (Eq. 2) 

521 dif_cot_meas = cot_meas[ix] - cot_meas[iy] # numerator term: cot(φ_meas_bpmx) − cot(φ_meas_bpmy) 

522 denom = dif_cot_model / betmdl1 # denominator term: (cot(φ_mdl_bpmx) − cot(φ_mdl_bpmy)) / β_mdl 

523 beta_i = dif_cot_meas / denom # β₁ = β_mdl · Δcot_meas / Δcot_mdl 

524 

525 # Alpha estimate at probed BPM for this triplet - derived from transport matrix ratio 

526 avg_cot_model = (cot_model[ix] + cot_model[iy]) / 2 

527 denomalf = 2 * (avg_cot_model + alfmdl1) # denominator term: cot(φ_mdl_bpmx) + cot(φ_mdl_bpmy) + 2α_mdl 

528 avg_cot_meas = (cot_meas[ix] + cot_meas[iy]) / 2 

529 alfa_i = 0.5 * (denomalf * dif_cot_meas / dif_cot_model - 2 * avg_cot_meas) 

530 

531 lng: int = len(outer_elmts) 

532 

533 # ----- Now the Jacobian rows for beta and alpha 

534 

535 # Sign factors for the Jacobian entries, corresponding to A_{ij}(λ) in paper Eq. (24) 

536 # fac1 = +1 if BPM j (ix) is to the left of probed BPM (ix < m) 

537 # fac1 = -1 if BPM j (ix) is to the right of probed BPM (ix > m) 

538 # (and vice versa for fac2 / BPM k) 

539 fac1: int = -np.sign(c[0] - m) 

540 fac2: int = np.sign(c[1] - m) 

541 

542 # Total length = (2m + 1) phase entries + 4 * n_elements systematic error entries 

543 line_length: int = 4 * len(outer_elmts.index) + 2 * m + 1 

544 outer_elmts_bet = outer_elmts.loc[:, "BETA"].to_numpy() 

545 outer_el_k2 = outer_elmts.loc[:, "K2L"].to_numpy() 

546 betaline = np.zeros(line_length) 

547 alfaline = np.zeros(line_length) 

548 

549 # # Locate BPMs j, k and probed BPM i in the element list, then derive the 

550 # contiguous slices of elements that lie between each reference BPM and the 

551 # probed BPM. These slices are where systematic errors contribute to the 

552 # phase advance (and then β and α) via the Jacobian. 

553 mloc: int = outer_elmts.index.get_loc(probed_bpm_name) # at m is the probed BPM 

554 xloc_r: int = outer_elmts.index.get_loc(outer_meas_phase_adv.index[ix]) # at x is first BPM in the triplet 

555 yloc_r: int = outer_elmts.index.get_loc(outer_meas_phase_adv.index[iy]) # at y is last BPM in the triplet 

556 

557 # Compute sin²(φ_mdl_bpmx − φ_mdl_1) and sin²(φ_mdl_bpmy − φ_mdl_1) 

558 # which show up in T^φ (Eq. 8) and T^K (Eq. 23) respectively 

559 denom_sinx = sin_squared_elements[xloc_r, m] 

560 denom_siny = sin_squared_elements[yloc_r, m] 

561 # Element index ranges between each BPM in the triplet and the probed BPM 

562 xmloc1, xmloc2 = min(xloc_r, mloc), max(xloc_r, mloc) 

563 ymloc1, ymloc2 = min(yloc_r, mloc), max(yloc_r, mloc) 

564 

565 # Get betas and sin for the elements in the slices: slice the 

566 # pre-computed sin² matrix and model arrays to the elements 

567 # in each [reference BPM <-> probed BPM] interval 

568 elem_ph_xa = sin_squared_elements[xmloc1:xmloc2, ix] 

569 elem_ph_ya = sin_squared_elements[ymloc1:ymloc2, iy] 

570 elem_beta_xa = outer_elmts_bet[xmloc1:xmloc2] 

571 elem_beta_ya = outer_elmts_bet[ymloc1:ymloc2] 

572 elem_k2_xa = outer_el_k2[xmloc1:xmloc2] 

573 elem_k2_ya = outer_el_k2[ymloc1:ymloc2] 

574 

575 # Common factor for all systematic error Jacobian entries in T^K 

576 bet_sin_ix = elem_ph_xa * elem_beta_xa / (denom_sinx * denom) 

577 bet_sin_iy = elem_ph_ya * elem_beta_ya / (denom_siny * denom) 

578 

579 # Index offsets into betaline/alfaline for each error source block: 

580 # T = (T^φ | T^K_dK1 | T^K_dX | T^K_KdS | T^K_mKdS) 

581 # Phase entries occupy [0 : range_of_bpms], systematic errors follow 

582 off1: int = range_of_bpms # T^K: dK1 block — quadrupole field errors (Eq. 23) 

583 off2: int = range_of_bpms + lng # T^K·K₂L: dX block — sextupole transverse misalignment (Eqs. 13-14) 

584 off3: int = range_of_bpms + 2 * lng # T^K: KdS — quad longitudinal misalignment, forward element (Sec. II.B) 

585 off4: int = range_of_bpms + 3 * lng # T^K: mKdS — quad longitudinal misalignment, backward/upstream element (Sec. II.B) 

586 

587 # Now below is the big summation over the contributing terms for the errors, 

588 # incl. phase uncertainty and systematic errors. 

589 

590 # apply phase uncertainty - T^φ entries: ∂β/∂φⱼ and ∂β/∂φₖ (Eq. 8) 

591 betaline[ix] = -1 / (denom_sinx * denom) 

592 betaline[iy] = 1 / (denom_siny * denom) 

593 # apply quadrupolar field uncertainty 

594 betaline[xmloc1 + off1 :xmloc2 + off1] += fac1 * bet_sin_ix 

595 betaline[ymloc1 + off1 :ymloc2 + off1] += fac2 * bet_sin_iy 

596 # apply sextupole transverse misalignment 

597 betaline[xmloc1 + off2 : xmloc2 + off2] += fac1 * elem_k2_xa * bet_sin_ix # the K2L shows up here 

598 betaline[ymloc1 + off2 : ymloc2 + off2] += fac2 * elem_k2_ya * bet_sin_iy # the K2L shows up here 

599 # apply quadrupole longitudinal misalignments 

600 betaline[xmloc1 + off3 : xmloc2 + off3] += fac1 * bet_sin_ix 

601 betaline[ymloc1 + off3 : ymloc2 + off3] += fac2 * bet_sin_iy 

602 betaline[xmloc1 + off4 : xmloc2 + off4] -= fac1 * bet_sin_ix 

603 betaline[ymloc1 + off4 : ymloc2 + off4] -= fac2 * bet_sin_iy 

604 

605 # The same thing is done for the alfaline 

606 

607 # apply phase uncertainty 

608 alfaline[ix] = -1 / (denom_sinx * denom * betmdl1) * denomalf + 1 / denom_sinx 

609 alfaline[iy] = 1 / (denom_siny * denom * betmdl1) * denomalf + 1 / denom_siny 

610 # apply quadrupolar field uncertainty 

611 alfaline[xmloc1 + off1 :xmloc2 + off1] += fac1 * (.5 * (bet_sin_ix * denomalf + bet_sin_ix / betmdl1 * dif_cot_meas)) 

612 alfaline[ymloc1 + off1 :ymloc2 + off1] += fac2 * (.5 * (bet_sin_iy * denomalf + bet_sin_iy / betmdl1 * dif_cot_meas)) 

613 # apply sextupole transverse misalignment 

614 alfaline[xmloc1 + off2 : xmloc2 + off2] += fac1 * elem_k2_xa * bet_sin_ix 

615 alfaline[ymloc1 + off2 : ymloc2 + off2] += fac2 * elem_k2_ya * bet_sin_iy 

616 # apply quadrupole longitudinal misalignments 

617 alfaline[xmloc1 + off3 : xmloc2 + off3] += fac1 * (.5 * elem_k2_xa * (bet_sin_ix * denomalf + bet_sin_ix / betmdl1 * dif_cot_meas)) 

618 alfaline[ymloc1 + off3 : ymloc2 + off3] += fac2 * (.5 * elem_k2_ya * (bet_sin_iy * denomalf + bet_sin_iy / betmdl1 * dif_cot_meas)) 

619 alfaline[xmloc1 + off4 : xmloc2 + off4] -= fac1 * (.5 * (bet_sin_ix * denomalf + bet_sin_ix / betmdl1 * dif_cot_meas)) 

620 alfaline[ymloc1 + off4 : ymloc2 + off4] -= fac2 * (.5 * (bet_sin_iy * denomalf + bet_sin_iy / betmdl1 * dif_cot_meas)) 

621 

622 return beta_i, alfa_i, betaline, alfaline

625def _covariant_weighting(mat: np.ndarray, col: np.ndarray) -> tuple[float, float]: 

626 """ 

627 Combines multiple estimates into a single BLUE (Best Linear Unbiased Estimator) 

628 weighted value with propagated uncertainty (Analytical N-BPM paper Appendix A, 

629 Eqs. A21-A22). 

630 

631 Given n_comb individual β (or α) estimates and their full covariance matrix V, 

632 the optimal weights are: 

633 

634 g_i = (Σ_k V⁻¹_{ik}) / (Σ_{j,k} V⁻¹_{jk}) (Eq. A21) 

635 

636 and the BLUE estimate and its variance are: 

637 

638 β̂ = Σ_i g_i β_i (Eq. A22) 

639 σ²_β̂ = gᵀ V g 

640 

641 The pseudo-inverse (pinv) is used instead of a regular inverse to handle 

642 near-singular covariance matrices (e.g. highly correlated triplets), with 

643 conditioning threshold RCOND. 

644 

645 Args: 

646 mat: (n_comb * n_comb) covariance matrix V of the individual estimates. 

647 col: 1D array of length n_comb holding the individual β or α estimates. 

648 

649 Returns: 

650 Tuple (estimate, uncertainty) where estimate is the BLUE-weighted scalar 

651 and uncertainty is its propagated 1σ error. 

652 

653 Raises: 

654 ValueError: if the sum of V⁻¹ is zero (degenerate / all-zero covariance matrix). 

655 """ 

656 mat_inv = np.linalg.pinv(mat, rcond=RCOND) # V⁻¹, pseudo-inverse for numerical stability 

657 wb = np.sum(mat_inv, axis=1) # g̃_i = Σ_k V⁻¹_{ik}: unnormalized BLUE weights (row sums) 

658 mat_inv_sum = np.sum(wb) # Σ_{j,k} V⁻¹_{jk}: normalization constant 

659 

660 if mat_inv_sum == 0: 

661 raise ValueError("Covariance weighting failed: the covariance matrix is degenerate") 

662 

663 # BLUE estimate: β̂ = g̃ᵀ col / Σ V⁻¹ (Eq. A22) 

664 # Propagated variance: σ²_β̂ = g̃ᵀ V g̃ / (Σ V⁻¹)² 

665 estimate: float = float(np.dot(wb.T, col) / mat_inv_sum) 

666 uncertainty: float = np.sqrt(np.dot(wb.T, np.dot(mat, wb)) / mat_inv_sum ** 2) 

667 return estimate, uncertainty

670def _assign_uncertainties(twiss_full: pd.DataFrame, errordefspath: Path | str) -> pd.DataFrame: 

671 """ 

672 Reads the definition file for systematic uncertainties and populates variance 

673 columns on ``twiss_full``, then filters out elements with no uncertainty assigned 

674 

675 All created output columns store **variances** (σ²), not standard deviations (σ). 

676 The error definition file provides rms σ values; and squaring is done in here. 

677 

678 Here are the output columns (variances) and how they map to error sources: 

679 

680 +----------+------------------------------------------------+-----------------------------------+ 

681 | Column | Physical meaning | Formula | 

682 +----------+------------------------------------------------+-----------------------------------+ 

683 | dK1 | Quadrupole relative field gradient error | σ²_ΔK1L = (dK1 · K1L)² | 

684 | dX | Sextupole transverse (horizontal) misalignment | σ²_ΔX = dX² | 

685 | KdS | Quadrupole longitudinal misalignment (forward) | σ²_KdS = (dS · K1L)² | 

686 | mKdS | Upstream drift of longitudinally misaligned | σ²_mKdS = KdS of previous elem | 

687 | | quad (thin-lens decomposition, Sec. II.B) | | 

688 | BPMdS | BPM longitudinal misalignment | σ²_BPMdS = dS² (stored, unused?) | 

689 +----------+------------------------------------------------+-----------------------------------+ 

690 

691 The PATTERN column in the error file is a regex matched against element names, 

692 or a `key:<name>` literal for a single named element. The MAINFIELD column 

693 distinguishes elements types. 

694 

695 Only elements with `UNC=True` are returned. This UNC flag is also set on the 

696 element immediately preceding a quadrupole with dK1 > 0 (to capture the upstream 

697 drift needed for the mKdS thin-lens term in Sec. II.B, Fig. 3). 

698 

699 Args: 

700 twiss_full: lattice element DataFrame (from ``accelerator.elements``), 

701 indexed by element name, containing at least K1L and K2L columns. 

702 errordefspath: path to the TFS systematic uncertainties definition file. 

703 

704 Returns: 

705 A filtered copy of ``twiss_full`` containing only elements with at least one 

706 non-zero variance, with added columns dK1, dX, KdS, mKdS, BPMdS (all σ²). 

707 """ 

708 LOGGER.debug("Loading systematic uncertainties") 

709 errdefs = tfs.read(errordefspath) 

710 twiss_full = twiss_full.assign(UNC=False, dK1=0.0, KdS=0.0, mKdS=0.0, dX=0.0, BPMdS=0.0) 

711 

712 # Loop over uncertainty definitions, each row matching a set of elements via 

713 # PATTERN, and assign the corresponding variance to the appropriate column. 

714 # Also set UNC to true on relevant elements. 

715 for indx in errdefs.index: 

716 patt = errdefs.loc[indx, "PATTERN"] 

717 if patt.startswith("key:"): 

718 LOGGER.debug(f"creating uncertainty information for {patt}") 

719 mask = patt.split(":")[1] 

720 else: 

721 reg = re.compile(patt) 

722 LOGGER.debug(f"creating uncertainty information for RegEx {patt}") 

723 mask = twiss_full.index.str.contains(reg) 

724 

725 # Quadrupole field error variance: σ²_ΔK1L = (relative_error · K1L)² 

726 twiss_full.loc[mask, "dK1"] = (errdefs.loc[indx, "dK1"] * twiss_full.loc[mask, "K1L"]) ** 2 

727 # Sextupole transverse misalignment variance: σ²_ΔX = dX² (used later with K2L for feeddown) 

728 twiss_full.loc[mask, "dX"] = errdefs.loc[indx, "dX"] ** 2 

729 if errdefs.loc[indx, "MAINFIELD"] == "BPM": 

730 # BPM longitudinal misalignment 

731 twiss_full.loc[mask, "BPMdS"] = errdefs.loc[indx, "dS"]**2 

732 else: 

733 # Quadrupole longitudinal misalignment variance: σ²_KdS = (dS · K1L)² 

734 twiss_full.loc[mask, "KdS"] = (errdefs.loc[indx, "dS"] * twiss_full.loc[mask, "K1L"]) ** 2 

735 twiss_full.loc[mask, "UNC"] = True # flag uncertainty assigned 

736 

737 # in case of quadrupole longitudinal misalignments, the element (DRIFT) in front of the 

738 # misaligned quadrupole will be used for the thin lens approximation of the misalignment: 

739 # mKdS is the KdS of the preceding element: in the thin-lens decomposition of a longitudinally 

740 # misaligned quadrupole (Sec. II.B, Fig. 3), the upstream drift element carries the backward 

741 # thin-lens kick, so its variance equals that of the quad it precedes 

742 twiss_full["mKdS"] = np.roll(twiss_full.loc[:]["KdS"], 1) 

743 # Also flag the element immediately before any quad with field errors as UNC=True, 

744 # so the mKdS entry of that element is included in the window slicing 

745 twiss_full.loc[:, "UNC"] = np.logical_or( 

746 abs(np.roll(twiss_full.loc[:, "dK1"], -1)) > 1.0e-12, twiss_full.loc[:, "UNC"] 

747 ) 

748 LOGGER.debug("Finished assigning variances from systematic uncertainties") 

749 return twiss_full.loc[twiss_full["UNC"]]

762def three_bpm_method( 

763 meas_input: DotDict, 

764 phase: PhaseDict, 

765 plane: str, 

766 meas_and_mdl_tunes: tuple[float, float], 

767) -> pd.DataFrame: 

768 """ 

769 Calculates betas and alphas using three adjacent-BPM triplet combinations 

770 (Castro, Ph.D. Thesis, University of Valencia, 1996). Unlike in the 

771 ``n_bpm_method`` this uses only the immediately neighbouring BPMs 

772 and propagates phase measurement uncertainties only (no systematic 

773 uncertainties for lattice errors). 

774 

775 For each probed BPM i, three triplets are formed and their β/β_mdl estimates 

776 are averaged arithmetically (see ``bet_frac`` below): 

777 - xxxABBx → probed BPM followed by two forward neighbours 

778 - xBBAxxx → two backward neighbours followed by probed BPM 

779 - xxBABxx → probed BPM flanked by skip-one neighbours 

780 

781 The input phase advance data from ``phase["MEAS"]``, ``phase["MODEL"]``, 

782 ``phase["ERRMEAS"]`` (from ``get_phases``) are of the form: 

783 

784 +----------+----------+----------+----------+----------+ 

785 | | BPM1 | BPM2 | BPM3 | BPM4 | 

786 +----------+----------+----------+----------+----------+ 

787 | BPM1 | 0 | phi_21 | phi_31 | phi_41 | 

788 +----------+----------+----------+----------+----------+ 

789 | BPM2 | phi_12 | 0 | phi_32 | phi_42 | 

790 +----------+----------+----------+----------+----------+ 

791 | BPM3 | phi_13 | phi_23 | 0 | phi_43 | 

792 +----------+----------+----------+----------+----------+ 

793 

794 and ``tilt_slice_matrix(matrix, shift, slice, tune)`` brings it into the form: 

795 

796 +-----------+--------+--------+--------+--------+ 

797 | | BPM1 | BPM2 | BPM3 | BPM4 | 

798 +-----------+--------+--------+--------+--------+ 

799 | BPM_(i-1) | phi_1n | phi_21 | phi_32 | phi_43 | 

800 +-----------+--------+--------+--------+--------+ 

801 | BPM_i | 0 | 0 | 0 | 0 | 

802 +-----------+--------+--------+--------+--------+ 

803 | BPM_(i+1) | phi_12 | phi_23 | phi_34 | phi_45 | 

804 +-----------+--------+--------+--------+--------+ 

805 

806 The computed ``cot_phase_*_shift1`` gives: 

807 

808 +-----------------------------+-----------------------------+-----------------------------+ 

809 | cot(phi_1n) - cot(phi_1n-1) | cot(phi_21) - cot(phi_2n) | cot(phi_32) - cot(phi_31) | 

810 +-----------------------------+-----------------------------+-----------------------------+ 

811 | NaN | NaN | NaN | 

812 +-----------------------------+-----------------------------+-----------------------------+ 

813 | NaN | NaN | NaN | 

814 +-----------------------------+-----------------------------+-----------------------------+ 

815 | cot(phi_13) - cot(phi_12) | cot(phi_24) - cot(phi_23) | cot(phi_35) - cot(phi_34) | 

816 +-----------------------------+-----------------------------+-----------------------------+ 

817 

818 -> for the combination xxxABBx: first row, 

819 -> for the combination xBBAxxx: fourth row, 

820 -> for the combination xxBABxx: second row of ``cot_phase_*_shift2``. 

821 

822 Args: 

823 meas_input: `OpticsInput` object with optics CLI options. 

824 phase: `PhaseDict` of phase matrices of measurement with errors and model tfs (bpm x bpm). 

825 plane: marking the horizontal or vertical plane, **X** or **Y**. 

826 meas_and_mdl_tunes: measured and model tunes. 

827 

828 Returns: 

829 `TfsDataFrame` containing betas and alfas from phase. 

830 """ 

831 # Ensure at least 3 BPMs so we can form one triplet 

832 if len(phase[MEASUREMENT].index) < 3: 

833 raise ValueError( 

834 "At least 3 BPMs are required for 3-BPM method. " 

835 f"Instead only {len(phase[MEASUREMENT].index)} were found in input." 

836 ) 

837 

838 tune, mdltune = meas_and_mdl_tunes 

839 beta_df = _get_filtered_model_df(meas_input, phase, plane) 

840 

841 # Tilt and slice so that for each probed BPM i the 5 rows hold (see docstring): 

842 # row 0: φ(i-2→j) two BPMs back 

843 # row 1: φ(i-1→j) one BPM back 

844 # row 2: 0, probed BPM i 

845 # row 3: φ(i+1→j), one BPM forward 

846 # row 4: φ(i+2→j), two BPMs forward 

847 # (see _tilt_slice_matrix for the rearrangement). Convert to radians 

848 tilted_meas = _tilt_slice_matrix(phase[MEASUREMENT].to_numpy(copy=True), 2, 5, tune) * PI2 

849 tilted_model = _tilt_slice_matrix(phase[MODEL].to_numpy(copy=True), 2, 5, mdltune) * PI2 

850 tilted_errmeas = _tilt_slice_matrix(phase[f"{ERR}{MEASUREMENT}"].to_numpy(copy=True), 2, 5, 0) * PI2 

851 

852 betmdl = beta_df.loc[:, f"{BETA}{plane}{MDL}"].to_numpy() 

853 alfmdl = beta_df.loc[:, f"{ALPHA}{plane}{MDL}"].to_numpy() 

854 

855 with np.errstate(divide="ignore"): 

856 cot_phase_meas = 1 / np.tan(tilted_meas) 

857 cot_phase_model = 1 / np.tan(tilted_model) 

858 

859 # Calculate numerators and denominators for far more cases than needed 

860 # shift1 are the cases BBA, ABB, AxBB, AxxBB etc. (the used BPMs are adjacent) 

861 # shift2 are the cases where the used BPMs are separated by one. only BAB is used for 3-BPM 

862 # Here EPSILON guards against a zero Δcot_mdl denominator (nearly degenerate triplet) 

863 cot_phase_meas_shift1 = cot_phase_meas - np.roll(cot_phase_meas, -1, axis=0) 

864 cot_phase_model_shift1 = cot_phase_model - np.roll(cot_phase_model, -1, axis=0) + EPSILON 

865 cot_phase_meas_shift2 = cot_phase_meas - np.roll(cot_phase_meas, -2, axis=0) 

866 cot_phase_model_shift2 = cot_phase_model - np.roll(cot_phase_model, -2, axis=0) + EPSILON 

867 

868 # Calculate β/β_mdl for each of the 3 triplets, which is Δcot_meas / Δcot_mdl 

869 # Here bet_frac is their arithmetic mean, so beti = β_mdl · mean(β/β_mdl) 

870 bet_frac = ( 

871 cot_phase_meas_shift1[0] / cot_phase_model_shift1[0] 

872 + cot_phase_meas_shift1[3] / cot_phase_model_shift1[3] 

873 + cot_phase_meas_shift2[1] / cot_phase_model_shift2[1] 

874 ) / 3 

875 

876 # Alpha model term: average of (cot φ_mdl,j + cot φ_mdl,k + 2α_mdl) / 2 

877 # across the 3 combinations 

878 alf_mdl_term = ( 

879 ((cot_phase_model + np.roll(cot_phase_model, -1, axis=0))[0] + 2.0 * alfmdl) 

880 + ((cot_phase_model + np.roll(cot_phase_model, -1, axis=0))[3] + 2.0 * alfmdl) 

881 + ((cot_phase_model + np.roll(cot_phase_model, -2, axis=0))[1] + 2.0 * alfmdl) 

882 ) / 6.0 

883 alf_meas_term = ( 

884 ((cot_phase_meas + np.roll(cot_phase_meas, -1, axis=0))[0]) 

885 + ((cot_phase_meas + np.roll(cot_phase_meas, -1, axis=0))[3]) 

886 + ((cot_phase_meas + np.roll(cot_phase_meas, -2, axis=0))[1]) 

887 ) / 6.0 

888 

889 # multiply the fractions by betmdl and calculate the arithmetic mean 

890 beti = bet_frac * betmdl 

891 alfi = bet_frac * alf_mdl_term + alf_meas_term 

892 

893 # Error propagation, from phase uncertainties 

894 # calculate errphi_ij^2 / sin^2 phimdl_ij * beta 

895 with np.errstate(divide="ignore", invalid="ignore"): 

896 sin_squared_model = tilted_errmeas**2 / np.square(np.sin(tilted_model)) * betmdl 

897 sin_quadrup_model = tilted_errmeas**2 / np.power(np.sin(tilted_model), 4) * betmdl 

898 

899 # Square to get variance terms (summed in quadrature across the two BPMs of each triplet) 

900 # These terms can be zero when model phase advances are multiples of pi (e.g. in SPS) so 

901 # we wrap it into the np.errstate context. 

902 sin_squared_model = np.square(sin_squared_model) 

903 with np.errstate(divide="ignore", invalid="ignore"): 

904 sin_squ_model_shift1 = sin_squared_model + np.roll(sin_squared_model, -1, axis=0) / np.square(cot_phase_model_shift1) 

905 sin_squ_model_shift2 = sin_squared_model + np.roll(sin_squared_model, -2, axis=0) / np.square(cot_phase_model_shift2) 

906 sin_quad_model_shift1 = sin_quadrup_model + np.roll(sin_quadrup_model, -1, axis=0) / np.square(cot_phase_model_shift1) 

907 sin_quad_model_shift2 = sin_quadrup_model + np.roll(sin_quadrup_model, -2, axis=0) / np.square(cot_phase_model_shift2) 

908 

909 # beterr = (1/3) · sqrt(Σ variance over 3 combinations): propagated σ_β 

910 beterr = np.sqrt(sin_squ_model_shift1[0] + sin_squ_model_shift1[3] + sin_squ_model_shift2[1]) / 3 

911 beta_df[f"{BETA}{plane}"] = beti 

912 beta_df[f"{ERR}{BETA}{plane}"] = beterr 

913 beta_df[f"{ALPHA}{plane}"] = alfi 

914 beta_df[f"{ERR}{ALPHA}{plane}"] = alf_mdl_term * beterr / betmdl + 0.5 * np.sqrt( 

915 sin_quad_model_shift1[0] + sin_quad_model_shift1[3] + sin_quad_model_shift2[1]) 

916 return _calc_and_add_delta_columns(beta_df, plane)

928def _tilt_slice_matrix( 

929 matrix: np.ndarray, slice_shift: int, slice_width: int, tune: float = 0.0 

930) -> np.ndarray: 

931 """ 

932 Tilts and slices the ``matrix``. 

933 Tilting means shifting each column upwards one step more than the previous columnns, i.e. 

934 

935 a a a a a a b c d 

936 b b b b b b c d e 

937 c c c c c --> c d e f 

938 ... ... 

939 y y y y y y z a b 

940 z z z z z z a b c 

941 

942 After tilting, the matrix is rolled by ``slice_shift`` rows so that the diagonal 

943 entry (where row index == column index, i.e. the probed BPM itself) lands at row 

944 ``slice_shift``. Only the first ``slice_width`` rows are returned, giving a local 

945 neighbourhood of BPMs centred on the probed one. 

946 

947 The ``tune`` argument corrects for the phase wrap at the ring boundary: entries 

948 that cross the 0->2π discontinuity are shifted by ±tune*2π to keep phases 

949 monotonically increasing (applied before tilting). 

950 

951 .. note:: 

952 Careful: this mutates the provided data. Be sure to provide a mutable 

953 array, ideally a copy and not a view. In pandas 3.x passing a view 

954 will error. 

955 

956 Args: 

957 matrix: (n_bpms * n_bpms) phase advance matrix to tilt. 

958 slice_shift: row index of the probed BPM in the output (= half-window size). 

959 slice_width: number of rows to return (= window size, typically 2*slice_shift + 1). 

960 tune: fractional tune, used to correct phases across the ring boundary. 

961 

962 Returns: 

963 (slice_width * n_bpms) array with phase advances in a rolling neighbourhood. 

964 """ 

965 invrange = matrix.shape[0] - 1 - np.arange(matrix.shape[0]) 

966 matrix[matrix.shape[0] - slice_shift :, :slice_shift] += tune 

967 matrix[:slice_shift, matrix.shape[1] - slice_shift :] -= tune 

968 return np.roll( 

969 matrix[np.arange(matrix.shape[0]), circulant(invrange)[invrange]], slice_shift, axis=0 

970 )[:slice_width]
